# Interview AI - AI-Powered Interview Coach

An AI-powered interview coaching web application that helps users practice interviews and improve their interview performance.

## 🚀 Live Demo

👉 https://interviewai-zk2fjbjn.manus.space/

## 📌 About the Project

I created Interview AI to help students and job seekers practice interviews in a more realistic way.

The application allows users to practice interview questions, record their responses, and receive AI-based feedback to understand areas where they can improve.

## ✨ Key Features

- 🎤 AI-powered interview practice
- 📹 Interview response recording
- 🤖 AI-based feedback
- 📊 Interview performance scoring
- 📄 Resume/CV analysis
- 🎯 Job-role based interview preparation
- 💡 Feedback on interview responses
- 📱 User-friendly interface

## 🎯 Purpose

The main goal of this project is to make interview preparation easier and more accessible for students and job seekers.

I built this project as a practical Product Management project to understand how AI can be used to solve real-world problems in the recruitment and interview preparation space.
